GO · POSTGRESQL · REDIS · DOCKER · NEXT.JS

TokoHerbal — Full-Stack Store

A herbal products store split into an auth service and a product service, each with its own PostgreSQL database, plus a Redis cache and a Next.js frontend. Everything runs with one docker compose up.

  • JWT access tokens with rotating refresh tokens
  • Redis cache and per-IP rate limiting that fail open when Redis is down
  • Circuit breaker between services, so a failing dependency doesn't hang requests
  • Stock is decremented atomically inside a database transaction
  • Separate customer and admin roles; admin accounts can't place orders
  • Unit tests and a GitHub Actions pipeline
